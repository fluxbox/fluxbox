Translations
------------

All translations live in nls/fluxbox-nls.yaml (UTF-8). Everything else
in nls/ is created from it: nls/*/generated*.m and nls/catalogs.am. Do not edit those files, edit the yaml file and run in nls/ ::

     uv run fluxbox-nls.py create-translation-files --in-yaml fluxbox-nls.yaml --out-folder .

A message not translated yet reads "‼ FIXME ‼" (or "!! FIXME !!" in
codesets without "‼"). The C text is the reference for all languages.

Adding a new translation
------------------------

1. Add your locale with its codesets under "codesets:", e.g. ::

     sv_SE:
     - ISO-8859-1
     - UTF-8

2. Add a text for your locale to every message under "sets:".
3. Run the command above, then ./autogen.sh and ./configure
   (in the upper directory).
